# Sprint 0

CS 449 Solitaire project. I'm building Peg Solitaire in Python with Pygame-CE and this is Sprint 0. This sprint has the unit tests and a starter menu GUI.

Please use the `main` branch, not `master`. I mixed up two GitHub accounts (CaldeJE2290 and jecalvil) so both show up as contributors, but they're both me.

The report for this assignment is located in the docs folder.

## Setup

Python 3.14.3, Pygame-CE 2.5.8, VS Code, unittest, Google Python Style Guide.

    pip install pygame-ce==2.5.8

## Running

Unit tests (from `sprint_0/unit_test`):

    # Run using your preferred Python command (e.g., python -m, py -m, or python3 -m)
    -m unittest test_calculator.py

Menu GUI (from `sprint_0/gui_programming`):

    # Run using your preferred Python command (e.g., python, py, or python3)
    gui.py
